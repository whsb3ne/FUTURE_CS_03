# 🔐 API Security Risk Analysis

## 📌 Target API
https://jsonplaceholder.typicode.com/users

---

## 📖 Overview
This project evaluates the security posture of a publicly accessible API endpoint. The goal is to identify potential vulnerabilities, analyze their impact, and propose mitigation strategies based on industry standards.

---

## 🎯 Objectives
- Assess API accessibility and behavior
- Identify security weaknesses
- Analyze potential risks
- Recommend security improvements
- Map findings to OWASP API Top 10

---

## 🧪 Methodology

### Tools Used
- Browser
- Postman
- cURL

### Testing Steps
1. Sent GET request to API endpoint
2. Observed JSON response
3. Analyzed exposed data fields
4. Evaluated authentication and access controls
